# Contrato de operaciones: Portada y documentación pública ARG

**Alcance**: Portada de repositorio como entrada al proyecto, documentación navegable, identidad argentina y participación comunitaria.

## Recorridos y datos mínimos

### Operación 1: Conocer el proyecto

Como visitante necesito entender propósito, estado y cómo instalar.

**Resultado**: Abrir README y encontrar propósito, cinco circuitos, autoría y enlaces de inicio.
**Excepción**: No presentar una especificación como función instalada ni prometer soporte contratado.

### Operación 2: Aprender por módulo

Como usuario necesito manual y tutorial compatibles.

**Resultado**: Encontrar manual y ficha de video por módulo, versión y estado.
**Excepción**: Ofrecer manual cuando no exista video vigente y no inventar canal o URL.

### Operación 3: Participar

Como colaborador necesito reglas, límites y tareas accesibles.

**Resultado**: Encontrar CONTRIBUTING, roadmap y plantilla de propuesta con referencia a spec.
**Excepción**: Evitar secretos, datos de clientes y material FactuSOL en aportes públicos.

## Invariantes

- El repositorio conserva documentación original y fuentes públicas con atribución.
- El sitio GitHub Pages es opcional posterior; README funciona sin desplegar otro servicio.
- No publicar credenciales, dumps, filestore ni referencias privadas de infraestructura.

Aplicar [contrato documental común](../../001-pyme-argentina/contracts/documentos.md),
[interfaz](../../001-pyme-argentina/contracts/interfaz.md) y
[soberanía](../../001-pyme-argentina/contracts/soberania.md).

No activar servicios externos por abrir una pantalla ni enviar datos sin acción de usuario autorizada.
Conservar ayuda/tutoriales por módulo y soporte general administrado centralmente.
