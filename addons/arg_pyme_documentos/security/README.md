# Seguridad
No hay tablas operativas nuevas ni ACL universales. Mixin y reportes abstractos conservan ACL del circuito.
Identidad en Base ARG, inmutable. Navegación filtra registros accesibles sin sudo; impresión exige ARG interno, compañía y ACL.
Adaptadores concretos deben declarar sus permisos, dependencias de indicadores y snapshot histórico.
