# Permisos de Interfaz ARG

No introduce modelos persistentes con datos operativos: hereda ir.http, res.users y mail.bot, y usa un servicio abstracto privado de instalación.
Los menús usan grupos de Base ARG. Los recursos de ayuda respetan ir.access de Base; las rutas requieren sesión interna.
Preferencias editables por su propio usuario mediante user_writeable nativo20. No se elevan fuentes operativas ni saldos.
La única elevación de lectura del controlador es sobre claves explícitas de contacto público, nunca secretos de proveedores.
