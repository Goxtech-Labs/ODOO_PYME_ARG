# Reportar problemas de seguridad

No publiques secretos, datos de clientes o detalles explotables en issues abiertos.
Para reportes privados de seguridad, escribí a [gonzalo@goxtech.com.ar](mailto:gonzalo@goxtech.com.ar), correo público del responsable elegido para este proyecto.
Compartí evidencia sanitizada y coordiná con el responsable antes de transmitir detalles sensibles.
Registrá versión, contexto, impacto y reproducción con datos ficticios. No pruebes sobre instalaciones ajenas.
La existencia de este documento no implica auditoría de seguridad ni soporte con SLA.
