# Aportar a Odoo Pymes ARG

Compartí un caso de gestión, una mejora documental, un tutorial o código ligado a una spec.
Describí problema, circuito, datos mínimos, comportamiento esperado y un ejemplo ficticio.
Antes de programar revisá constitución, contratos y dependencias en docs/INDICE.md.
Trabajá en rama/worktree propio y proponé cambios pequeños con evidencia técnica y límites declarados.

No adjuntes contraseñas, CUIT o datos de terceros, copias de bases, filestore ni código sin licencia compatible.
Las capturas FactuSOL son referencia privada de organización funcional; los recursos del proyecto deben ser originales.
Respetá autorías y explicá dependencias. El conocimiento compartido y la participación no requieren contratar servicios.
