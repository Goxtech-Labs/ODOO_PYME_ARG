# Base ARG · uso

Compatibilidad: Odoo 20 Community. La versión de cada addon está fijada en la
[composición de esta entrega](../../composition/versions.lock.json); consultar sus límites y estado de QA.

Instalado en arg_demo: versión 20.0.1.0.3. QA funcional pendiente.
Gestión ARG ofrece tipos documentales y catálogo de ayuda. Administrador administra; operadores consultan.
Cada compañía recibe 17 tipos con secuencias independientes. No escribir números manualmente ni confundir FAC con número fiscal.
Un mismo usuario puede combinar roles por circuito. La configuración avanzada de usuarios conserva controles nativos.
Manuales/tutoriales permiten versión, revisión, reemplazo y guía escrita. Sólo un video vigente/compatible se abre como tutorial.
Soporte general: el administrador de Odoo configura correo, WhatsApp o tickets en Ajustes/Gestión ARG; sin destinos inventados.
No se envían mensajes por guardar ajustes ni por abrir ayuda. Los botones y acceso contextual se completan con Interfaz ARG.
