# Recursos gráficos ARG

## Industria y gestión argentinas

Recurso original de ilustración IA: [industria-arg-hero-v1.png](../addons/arg_pyme_ui/static/img/industria-arg-hero-v1.png).
Generado con la herramienta integrada de imágenes, preservando el original y copiando el resultado
al addon. Escena ficticia; no representa una fábrica o empresa real. Se usa en Inicio y acceso.
Recursos originales ARG: CC BY-SA 4.0, según [NOTICE](../NOTICE.md).

Dirección creativa: ilustración panorámica de una pyme industrial argentina, taller/fábrica,
almacenamiento y logística, gestión mediante documentos y gráficos, bandera argentina con sol,
paleta celeste/blanco/azul y pequeños acentos dorados, composición limpia con espacio a la izquierda
para texto HTML, sin texto incrustado, marcas ni logos ajenos. El texto y los botones se renderizan
como interfaz accesible, no dentro de la imagen.

## Iconos Lucide

Subconjunto de 34 SVG de `lucide-static` 1.66.0, descargado del registro npm oficial; integridad
SHA512 comprobada antes de extraer sólo SVG y licencia. No se instalaron scripts ni paquetes.
[Procedencia, integridad y lista](../addons/arg_pyme_ui/static/icons/lucide/SOURCE.json).
[Licencia íntegra ISC y atribuciones MIT de Feather](../addons/arg_pyme_ui/static/icons/lucide/LICENSE).
[Licencia oficial](https://lucide.dev/license).

Iconos locales con texto en controles. No requieren CDN, API ni conexión para mostrarse. Su licencia
se conserva; no se relicencian como creación original ARG. Inspiración de organización en cintas de
comandos, sin incorporar recursos de Microsoft ni capturas de FactuSOL.

## Cambios de recursos

Crear nueva versión de nombre al reemplazar una ilustración. Mantener procedencia, licencia,
consumidores y vista en ambos temas. No usar imágenes para simular botones o campos funcionales.
