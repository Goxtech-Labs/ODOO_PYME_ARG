# Aportar a ARG

La [guía de contribución del repositorio](../../CONTRIBUTING.md) es la fuente canónica.
Compartí un caso de gestión, documentación, ejemplos ficticios o código enlazado a una spec.

1. Identificá circuito y problema; revisá el [roadmap](ROADMAP.md) y contratos.
2. Completá la [propuesta](comunidad/PROPUESTA.md), con datos mínimos y resultado esperado.
3. Prepará un cambio propio en una rama o worktree, con autoría y licencia compatible.
4. Declará controles técnicos y límites; reservá QA funcional para la fase acordada.
5. Proponé revisión sin publicar secretos, datos de clientes ni capturas ajenas.
