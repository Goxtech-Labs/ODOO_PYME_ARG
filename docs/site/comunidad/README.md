# Una comunidad que comparte gestión y tecnología

ARG nace para acercar herramientas y conocimiento a todas las pymes posibles.
No hace falta contratar servicios profesionales para usarlo, aprender o participar.
Una experiencia de negocio, una explicación más clara o un error bien descrito también son aportes.

Los canales oficiales de comunidad, soporte y YouTube se comunicarán cuando estén configurados.
No hay un correo, número de WhatsApp ni sistema de tickets inventado en esta portada.
El centro de soporte de cada instalación permite definir los destinos administrados por su responsable.
