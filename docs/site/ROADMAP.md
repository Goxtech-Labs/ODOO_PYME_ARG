# Roadmap ARG

## Núcleo instalado técnicamente

Base, Interfaz, Terceros, Catálogo, Motor documental, Ventas, Compras, Stock, Administración e Informes,
con puentes de Ventas–Stock y Compras–Stock. Doce addons ARG. Código y composición fijados por entrega.
La revisión funcional/visual con el usuario sigue pendiente; no hay homologación fiscal implícita.

## Preparación de publicación

Portada, manuales, guías de instalación/recuperación, catálogo editorial, licencias y reglas comunitarias.
Se preparan fuentes y avisos de cada dependencia; el registro de release distingue preparación y publicación.
No hay activación automática de GitHub Pages, canal de YouTube ni mensajería.

## Revisión posterior con la comunidad

Recorridos de aceptación, accesibilidad visual, roles, múltiples compañías, parciales, concurrencia,
reversiones y restauración de instalaciones propias. Cada caso usa datos ficticios o autorizados.
Los hallazgos se enlazan a una spec y se corrigen en incrementos verificables.

## Después del núcleo

Un único addon Integraciones ARG, con adaptadores internos por proveedor. ARCA será un incremento
con homologación y autorización propias. Rubros y personalizaciones se agregan con nuevas specs
según necesidades confirmadas; no se inventa una primera vertical.
