# Aprender por módulo y versión

La fuente editorial única es [catalogo.json](../../comunidad/youtube/catalogo.json).
El [índice YAML](catalogo.yml) apunta a ella; no mantiene una segunda lista de URLs.
[Manuales por módulo](../MANUALES.md) es la entrada de lectura sin video.

Cada ficha conserva módulo/feature, tarea, versión mínima/máxima, manual, estado, responsable,
fecha de revisión y reemplazo. Un video planeado no aparece como vigente y no tiene URL ficticia.
La ayuda de Odoo usa un catálogo editable de la instalación: actualizar una URL no exige reinstalar.
El repositorio es semilla editorial y no sobrescribe personalizaciones del usuario.

| Estado | Qué significa |
| --- | --- |
| Planeado | Hay tema o guion, todavía no un video publicado |
| Vigente | Video real revisado para las versiones indicadas |
| Por revisar | Un cambio exige comprobar compatibilidad |
| Reemplazado | Se conserva historia y se indica la ficha nueva |
