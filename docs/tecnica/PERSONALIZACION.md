# Programar y personalizar con personas o agentes

Leer AGENTS.md, constitución, índice de specs y contratos antes de editar.
Trabajar en worktree propio, fijar una feature y respetar dependencias. No modificar core ni usar datos reales.
Crear addon con manifest, licencia revisada, modelos, permisos, vistas y documentación.
Validar APIs contra el runtime instalado; las referencias de otro Odoo son inspiración, no contratos vigentes.

Primer incremento: Base ARG (002). Después UI, maestros y Documentos; recién entonces Ventas.
Definir un cambio pequeño con criterio verificable, implementarlo, controlar sintaxis/instalación y entregar para QA posterior.
No generar todos los módulos a la vez. No confundir tarea terminada con aceptación del usuario.

Una IA puede ayudar a redactar, desarrollar y documentar; no es requerida para operar el sistema.
No enviar DB, secretos o documentos de clientes a proveedores externos sin autorización explícita.
Preferir ejemplos anónimos, contratos y errores sanitizados. Toda propuesta debe preservar fuente única y soberanía.
