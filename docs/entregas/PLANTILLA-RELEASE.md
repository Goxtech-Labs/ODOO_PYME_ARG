# Registro de entrega

Identificar versión/SHA, módulos, dependencias nativas, migraciones y cambios de contrato.
Registrar entorno, fecha, backup/snapshot, controles técnicos y evidencia sanitizada.
Separar estados: especificado → programado → instalado → QA realizado → aceptado → publicado.
Enumerar límites, pendientes, tutoriales afectados, compatibilidad y plan de reversión sin pérdida de datos nuevos.
Nunca incluir secretos ni afirmar pruebas que no se ejecutaron.
