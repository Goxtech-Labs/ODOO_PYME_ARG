# Ficha de tutorial

Registrar: identificador, título, addon/feature, tarea, versión mínima/máxima, idioma, URL, fecha de revisión,
responsable, estado (planeado/vigente/revisar/retirado), reemplazo y manual alternativo.

Guion: problema de una pyme → datos mínimos → recorrido en orden habitual → resultado → excepción → enlace al manual.
Usar capítulos cortos, subtítulos y ejemplos sin datos personales. Mostrar PRE y PED con identidades distintas cuando corresponda.
La miniatura usa celeste/blanco y texto legible; nunca reutilizar capturas ajenas como identidad del proyecto.
