# Mantener tutoriales

Cada cambio de interfaz o regla identifica fichas afectadas antes de release.
Revisar compatibilidad de versión, indicar vigencia, vincular reemplazo y conservar manual actualizado.
Actualizar URL y estado desde catálogo Base ARG sin reinstalar addons.
Si falta URL, se muestra manual y estado del contenido; no un botón roto.
El catálogo editorial del repositorio sirve de semilla documental, no sobrescribe la configuración local del usuario.
