# Conocimiento compartido

Este proyecto nace para poner experiencia tecnológica y de gestión a disposición de las pymes.
Gonzalo Sarubilo aporta más de 20 años de experiencia declarada y aprende de cada nuevo uso comunitario.
Cada mejora debe volver como código, explicación, ejemplo o guía que otra pyme pueda adaptar.
La consultoría existe como opción secundaria; no es condición de acceso al conocimiento ni al sistema.

Recibir propuestas por los canales que el responsable publique. Priorizar impacto común, claridad, mantenimiento y soberanía.
Documentar decisiones, reconocer aportantes y usar ejemplos sin datos privados. El soporte comunitario no promete SLA comercial.
